# SEAM

بینش قراردادهای میان‌زبانی، بر پایهٔ شواهد.

بفهمید چه چیزی بخش‌های نرم‌افزارتان را به هم وصل می‌کند، ثابت کنید چرا به هم وصل‌اند، و دریابید وقتی این اتصال‌ها می‌شکنند چه چیزی تغییر می‌کند.

SEAM مرزهای میان بخش‌هایی از یک سیستم را پیدا می‌کند که جدا از هم ساخته شده‌اند؛ برای نمونه، یک کلاینت TypeScript که یک API پایتونی را صدا می‌زند و آن API هم از یک جدول Postgres می‌خواند. هر کدام از این مرزها به‌صورت یک **درز** (Seam) ثبت می‌شود: با تولیدکننده و مصرف‌کننده، قرارداد، نگاشت فیلدها، شواهد، و دسته‌بندیِ صادقانه‌ای از اینکه تا چه حد اثبات شده است.

**وضعیت: مراحل نخستِ توسعه.** مدل دامنه و قواعد آن پیاده‌سازی و آزموده شده‌اند؛ آداپتورهای زبان، لایهٔ ذخیره‌سازی و فرمان `seam` در دست ساخت‌اند. اینکه دقیقاً چه چیزی کار می‌کند را در [docs/PROJECT_STATUS.md](docs/PROJECT_STATUS.md) ببینید.
