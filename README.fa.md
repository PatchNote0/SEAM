# SEAM

بینش قراردادهای میان‌زبانی، بر پایهٔ شواهد.

SEAM مرزهای میان بخش‌هایی از یک سیستم را پیدا می‌کند که جدا از هم ساخته شده‌اند؛ برای نمونه، یک کلاینت TypeScript که یک سرویس FastAPI را صدا می‌زند، سرویسی که یک سند OpenAPI توصیفش می‌کند و Docker Compose آن را به بقیه وصل می‌کند. SEAM هر مرز را به‌صورت یک **درز** (Seam) ثبت می‌کند: چه کسی چه کسی را صدا می‌زند، از کدام مسیر، با کدام فیلدها، با استناد به کدام خطوط کد، و SEAM تا چه اندازه از آن مطمئن است.

</div>

```text
$ seam scan --lang fa
GET /accounts/{account_id}  تأییدشده (VERIFIED)
  @ledgerline/web (fetchAccount) → ledgerline-api (get_account)
  sm_hajbrsw7xvh8h76etgjg · قرارداد getAccount
```

<div dir="rtl" lang="fa">

و یافته‌ای که زیر آن چاپ می‌شود:

**شکننده:** مصرف‌کننده `name` را می‌خواند؛ پاسخ تولیدکننده فیلدی به نام `name` ندارد.

این یافته از [نمونهٔ چندزبانه](fixtures/polyglot/FIXTURE.md) می‌آید: API فیلد `name` را به `display_name` تغییر نام داده، کلاینت هنوز `name` را می‌خواند، و آزمون‌های خود کلاینت قبول می‌شوند چون پاسخ قدیمی را شبیه‌سازی می‌کنند.

## نصب

فایل فشردهٔ مخصوص سیستم خود را از [آخرین نسخه](https://github.com/PatchNote0/seam/releases/latest) بگیرید، از حالت فشرده خارج کنید و `seam` را در `PATH` قرار دهید.

| سیستم | فایل |
|---|---|
| ویندوز، x64 | `seam-<version>-x86_64-pc-windows-msvc.zip` |
| macOS، اپل سیلیکون | `seam-<version>-aarch64-apple-darwin.tar.gz` |
| macOS، اینتل | `seam-<version>-x86_64-apple-darwin.tar.gz` |
| لینوکس، x64 (ایستا) | `seam-<version>-x86_64-unknown-linux-musl.tar.gz` |
| لینوکس، ARM64 (ایستا) | `seam-<version>-aarch64-unknown-linux-musl.tar.gz` |

هر نسخه یک فایل `SHA256SUMS` دارد. فایل‌های اجرایی هنوز امضای دیجیتال ندارند. در macOS، علامت قرنطینهٔ دانلود را با `xattr -d com.apple.quarantine ./seam` بردارید. در ویندوز ممکن است SmartScreen بار اول از شما تأیید بخواهد.

همین برنامه به‌صورت ایمیج کانتینر هم منتشر می‌شود:

</div>

```sh
docker run --rm -v "$PWD:/repo" ghcr.io/patchnote0/seam scan /repo --no-store --lang fa
```

<div dir="rtl" lang="fa">

برای ساختن از روی کد به Rust نسخهٔ 1.90 یا بالاتر و یک کامپایلر C نیاز دارید (گرامرهای tree-sitter و SQLite همراه برنامه کامپایل می‌شوند):

</div>

```sh
cargo install --locked --git https://github.com/PatchNote0/seam seam-cli
```

## استفاده

| فرمان | کارش |
|---|---|
| `seam scan [PATH]` | مخزن را اسکن می‌کند، یک تصویر لحظه‌ای در `PATH/.seam/seam.db` ثبت می‌کند و درزها را با یافته‌هایشان چاپ می‌کند. |
| `seam seams [PATH]` | دفتر درزها: همهٔ درزهای آخرین اسکن با وضعیت چرخهٔ عمرشان، و درزهایی که از آن پس حذف شده‌اند. |
| `seam explain ID` | گذرنامهٔ شواهد یک درز: چرا SEAM به آن باور دارد، مقایسهٔ تک‌تک فیلدها، فرض‌ها، آزمون‌ها، و خطوط کدی که پشت هر ادعاست، که دوباره با فایل‌های فعلی سنجیده می‌شوند. |
| `seam report [PATH]` | بدون ثبت، اسکن می‌کند و گزارشی به‌صورت JSON (`seam-report/1`) یا Markdown می‌نویسد. |
| `seam languages` | آنچه هر مبدل می‌خواند، در میان فایل‌ها دنبال می‌کند، یا پشتیبانی نمی‌کند. |

فرمان `seam scan --fail-on breaking` اگر یافتهٔ شکننده‌ای وجود داشته باشد با کد خروج 1 تمام می‌شود، برای استفاده در CI. همهٔ فرمان‌ها، گزینه‌ها، قالب‌های خروجی و کدهای خروج در [docs/CLI.md](docs/CLI.md) آمده‌اند (به انگلیسی).

## آنچه می‌خواند

| سو | آنچه خوانده می‌شود |
|---|---|
| کلاینت‌ها | TypeScript و JavaScript: فراخوانی‌های `fetch` و `axios`، که از میان تابع‌های پوشاننده، ثابت‌ها، importها و `import.meta.env` یا `process.env` همراه با مقدار پیش‌فرضشان دنبال می‌شوند. |
| سرویس‌ها | Python FastAPI: مسیرها، پیشوندهای روتر و `include_router` در میان ماژول‌ها، مدل‌های Pydantic با aliasها و ارث‌بری. |
| قراردادها | OpenAPI 3.0 و 3.1 در YAML یا JSON، همراه با `$ref` محلی. |
| اتصال‌ها | Docker Compose: کدام سرویس کدام پوشه را می‌سازد و چه متغیرهای محیطی‌ای تعیین می‌کند. |
| آزمون‌ها | بلوک‌های `it` و `test` در Vitest یا Jest، و درخواست‌های `TestClient` در FastAPI. |

فرمان `seam languages --lang fa` فهرست کامل توانایی‌ها را به فارسی چاپ می‌کند، از جمله آنچه پشتیبانی نمی‌شود.

## میزان اطمینان

هر درز یک رده دارد که ضعیف‌ترین حلقهٔ زنجیرهٔ شواهدش آن را تعیین می‌کند.

| رده | معنا |
|---|---|
| تأییدشده (`VERIFIED`) | همهٔ حلقه‌ها واقعیت‌های صریح یا گام‌های قطعی‌اند و هیچ فرضی لازم نبوده است. |
| استنتاج‌شده (`INFERRED`) | تطبیق به یک فرض نیاز داشته که همراه کدی که آن را لازم کرده نوشته می‌شود. |
| تجزیه‌شده (`PARSED`) | یک سو از کد خوانده شده، اما طرف مقابلش پیدا نشده است. |
| نامعلوم (`UNKNOWN`) | مقصد هنگام اجرا محاسبه می‌شود؛ فراخوانی ثبت می‌شود، نه حدس زده. |

اطمینان «قوی»، «متوسط» یا «ضعیف» است، همیشه همراه دلایلش و هرگز به‌صورت درصد.

## حریم خصوصی

SEAM فقط فایل‌ها را می‌خواند و یک پایگاه دادهٔ محلی می‌نویسد. هیچ اتصال شبکه‌ای باز نمی‌کند، هیچ چیزی از مخزن تحلیل‌شده را اجرا نمی‌کند، داده‌ای دربارهٔ استفاده نمی‌فرستد و به حساب کاربری نیاز ندارد. فایل‌هایی که معمولاً رمز و کلید در خود دارند (`.env`، کلیدها، `.npmrc`) هرگز خوانده نمی‌شوند و خروجی اسکن آن‌ها را به‌عنوان «کنارگذاشته» نام می‌برد.

## فارسی

همهٔ خروجی‌های خواندنی برای انسان به فارسی هم در دسترس‌اند: گزینهٔ `--lang fa` را بدهید یا `SEAM_LANG=fa` را تنظیم کنید. فرمان `seam report --format markdown --lang fa` گزارشی راست‌به‌چپ می‌نویسد که در هر نمایشگر Markdown به‌خوبی خوانده می‌شود. خروجی JSON همیشه انگلیسی است.

ترمینال‌ها در نمایش متن راست‌به‌چپ یکسان نیستند. اگر سطرهای فارسی در ترمینال شما وارونه دیده می‌شوند، گزارش Markdown فارسی را باز کنید. متن راهنمای فرمان‌ها (`--help`) فعلاً انگلیسی است.

## وضعیت

نسخهٔ 0.1.0 نخستین نسخهٔ عمومی است و درزهای HTTP میان کلاینت‌های TypeScript یا JavaScript و سرویس‌های FastAPI را پوشش می‌دهد. درزهای SQL، متغیرهای محیطی و Rust (Axum)، تاریخچهٔ Git و «تمرین تغییر»، پایش فایل‌ها و برنامهٔ دسکتاپ در برنامه‌اند و هنوز ساخته نشده‌اند. فهرست دقیق آنچه کار می‌کند و نحوهٔ آزمودنش در [docs/PROJECT_STATUS.md](docs/PROJECT_STATUS.md) آمده است.
